# Manual Testing

This folder contains standalone manual testing practice exercises and
reusable checklists — focused, feature-level testing work that
demonstrates breadth across different UI patterns, separate from the
full end-to-end projects and theory notes elsewhere in this portfolio.

## Why This Folder Exists

Rather than duplicating the full end-to-end projects in
[`06-Projects`](../06-Projects) or the conceptual theory in
[`07-Notes`](../07-Notes), this folder demonstrates how the same testing
mindset applies quickly across different, common UI patterns — the kind of
feature a QA Analyst is asked to test on short notice, without a full
project cycle around it.
