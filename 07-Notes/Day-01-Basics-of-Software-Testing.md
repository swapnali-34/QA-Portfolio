1. What is Software Testing?
    Software Testing is the process of verifying and validating a software application to ensure it works as expected and is free from defects.

  The main goal of software testing is to identify bugs before the software is released to users.

  Objectives
    - Find defects or bugs.
    - Ensure the software meets business requirements.
    - Improve software quality.
    - Increase customer satisfaction.
    - Reduce the cost of fixing defects after release.
  Example:
  Suppose a login page accepts an incorrect password and still logs the user in.
  This is a bug, and testing helps identify it before customers use the application.

2. SDLC (Software Development Life Cycle):
   Requirements-> Planning-> Design-> Development-> Testing-> Deployment-> Maintenance

3. STLC (Software Testing Life Cycle):
   Requirement Analysis-> Test Planning-> Test Case Development-> Environment Setup-> Test Execution-> Defect Reporting-> Test Closure

4. Defect (Bug):
  A defect (or bug) is a flaw in software that causes the application to behave differently from the expected result.

  Example:
  Expected Result
  Entering the correct username and password should log the user in.
  
  Actual Result
  The application displays an error message even though the credentials are correct.
  
  This is a defect.

  Bug Life Cycle:
  New-> Assigned-> Open-> fixed-> Retest-> Closed

5. Verification vs Validation
   | Verification                                     | Validation                                                             |
| ------------------------------------------------ | ---------------------------------------------------------------------- |
| Checks whether the product is built correctly.   | Checks whether the right product is built.                             |
| Process-oriented.                                | Product-oriented.                                                      |
| Performed before execution.                      | Performed after execution.                                             |
| No code execution required.                      | Requires executing the software.                                       |
| Includes reviews, inspections, and walkthroughs. | Includes functional, integration, system, and user acceptance testing. |
